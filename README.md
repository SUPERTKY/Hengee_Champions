# Hengee Champions

ブラウザで動くタイトル画面の土台です。リポジトリをダウンロードし、`index.html` をブラウザで開いてください。ビルドや追加ライブラリは不要です。

## 起動演出

- 起動後、最初の2秒間は黒い画面のまま待機します。
- `assets/sounds/Title.mp3` の再生開始に合わせて、中央の `assets/images/Icon.png` を1秒でフェードインします。
- 表示完了から2秒間待ち、1.5秒でアイコンをフェードアウトします。
- 消え終わって0.5秒後、仮タイトル画面を1.5秒でフェードインします。
- 音楽は画面切り替え時に停止・巻き戻し・フェードアウトせず、ループ再生を続けます。

ブラウザが音声の自動再生を許可しない場合だけ、開始ボタンを表示します。ボタンをタップ・クリック、またはキーボードで選択して開始すると、音楽と演出が同時に始まります。

## 編集

演出の時間は `title.js` の `TIMING` にミリ秒単位でまとまっています。
次の画面は `index.html` の `#title-screen` を編集してください。音楽を途切れさせないため、ページ遷移ではなく同じページ内で画面を切り替えます。

## 動作確認

1. 起動後2秒間は黒い画面が続き、その後アイコンのフェードインと音楽が始まること。
2. 自動再生が許可される場合は操作なし、制限される場合は開始ボタンから演出と音楽が始まること。
3. アイコン表示後2秒の保持、1.5秒の消去、0.5秒の暗転待機の順番になること。
4. 次の画面への移行で曲が停止したり先頭に戻ったりしないこと。
5. スマートフォンの縦横表示でもアイコンが中央に収まること。
